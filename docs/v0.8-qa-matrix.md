# RustShot v0.8.0 — quality/refinement acceptance

Scope: existing screenshot and annotation features only. No emoji, OCR, translation, scroll capture, pinning or sharing.

## Core UX regression matrix (Windows 11 manual)

| Scenario | Pass criteria |
|---|---|
| Draw 2 rectangles, then move crop repeatedly | Both rectangles follow crop, retain original styles |
| Draw arrow, undo it, move crop, redo | Redone arrow appears translated with crop |
| Drag crop flush to screen edge and continue moving cursor | Annotations stop moving exactly when clamped crop stops; no drift |
| Resize crop from any of 8 handles with existing annotations | Nothing is silently erased; new crop clips pixels outside region |
| Resize crop smaller then larger | Original annotations become visible again if included |
| Resize/crop on second monitor with negative desktop coordinates | No jumps, wrong cursor targets or overflow |
| Hover eight resize points | Two diagonal, horizontal, vertical cursor orientations correct |
| Hover enabled toolbar actions, disabled OCR etc. | Hand only over enabled controls, arrow over disabled placeholders |
| Choose Text; enter Chinese via Microsoft Pinyin/third-party IME | Candidate confirmation does not commit early; text visible on overlay *before* export |
| Commit text then Undo/Redo | Text disappears/reappears and retains position, font and color |
| Resize text selection, then cancel text input | Native EDIT font handles return to baseline; no stale child window |
| Draw red/blue arrow, then mosaic across earlier drawing | Preview pixelates the earlier stroke, as export does; later drawing stays visible |
| Multiple mosaic rectangles and overlapping annotations | Layer order consistent with exported PNG |
| Repeatedly drag selection rapidly (100 times) | No black/white flicker regression from v0.4.1 |
| Background 10 hours, capture 1000 times | No accumulating GDI objects, handles, or memory |
| 1080p/2K/4K, 100/125/150/200% scaling | Tooltip, annotation palette, cursor and font align with physical-pixel hit areas |
| PNG AutoSave off / AutoCopy on and vice versa | Settings retained independently, each successful output unaffected |
| IME composition then Escape or Enter | No unexpected screenshot completion or duplicate text |

## Code-level checks

- `Annotation::translate` uses saturating coordinate addition; both committed and redo collections move
- Only the *difference between successive clamped crop positions* is applied to annotation coordinates
- Crop resizing preserves source points; rendering clips them to the selection
- Text preview eligibility explicitly accepts single-point text annotations
- Text input control GDI font object lifetime is bounded by the EDIT control lifetime
- Mosaic preview uses earlier annotations in original order before pixelating the mosaic region
- The v0.4.1 double-buffered overlay is left unchanged
- All CI tests/lints/release builds must pass before merge

## Known limits

Unit tests and Windows CI cannot prove real Windows IME candidate behavior, cursor shape correctness across drivers, actual GPU composition, absence of leaks over hours, or pixel-exact image previews. The user must test the portable build for these. Mosaic preview may still differ at clipping boundaries due to the separate GDI text rasterizer; compare live screenshots with exported images to identify residual discrepancies.
