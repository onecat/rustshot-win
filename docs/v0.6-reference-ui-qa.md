# RustShot v0.6 — WeChat reference UI QA

Source reference provided in chat: three screenshots of WeChat PC capture tool, measuring **941×757**, **1752×604** (enlarged closeup), and **638×398**. Those screenshot files are not copied into the public source repository.

## Geometry mapping for full toolbar

- Bar approximately **824 × 52** reference pixels; below selection, 14 px gap; white fill, small 12px GDI rounded corners, thin gray border, subtle shadow.
- 16 item centers from the first reference relative to toolbar X: `[38,84,130,178,225,272,320,386,437,485,550,597,645,691,737,784]`
- Sequence: rectangle, ellipse, emoji, arrow, pen, mosaic, text | translate (disabled), OCR (disabled), scroll (disabled) | undo, save, pin (disabled), share (disabled), red cancel X, green finish ✓.
- Tooltip is positioned below the toolbar when it fits, otherwise above.
- Selection uses a 2px green border and eight solid approximately 7px squares, size label at top-left using `width x height`.

## Compact profile

- For narrow virtual desktops (width under 900 physical px), toolbar size **556×41** and gap **3px**, matching the small screenshot more closely.
- 12 item centers relative to X: `[38,80,123,168,210,252,296,339,402,444,488,530]`
- Sequence: rectangle, ellipse, emoji, arrow, pen, mosaic, text | undo | share (disabled), save, cancel, finish.
- On extremely narrow desktops, icon hit rects scale uniformly, and every cell remains inside virtual desktop.

## Windows 11 manual verification checklist

- [ ] 100% and 125% DPI at 1080p — green border, handles and icons visually aligned.
- [ ] 150% DPI 4K — no clipping or misaligned hit boxes.
- [ ] Dual monitor with negative X/Y — bar stays within desktop, correct hover.
- [ ] Crops flush against right/bottom of screen — bar flips above when necessary.
- [ ] Larger crop — full toolbar with 16 icons, correct reference order.
- [ ] Virtual desktop narrower than 900 physical pixels — compact bar and separator layout.
- [ ] Disabled icons — gray with tooltip, no mouse capture, do not change selection or complete screenshot.
- [ ] Save icon (disk/down arrow) — valid PNG and clipboard, closes capture like Finish.
- [ ] Green check and red X — complete/cancel, buttons do not swap.
- [ ] After Pen, press V — selection/move tool available again without adding a non-reference toolbar icon.
- [ ] Rect/Ellipse/Arrow/Pen/Mosaic/Text/Undo/ Ctrl+Y — no regression.
- [ ] Press Alt+A, drag selection quickly / resize repeatedly — no black/white flashing (v0.4.1 regression).
- [ ] CJK IME and hover tooltip — no flicker, misplacement or focus loss.
- [ ] Loop 100 captures and 10h idle — no persistent GDI/memory handle leak.

## Limits of claims

Passing Windows CI confirms fmt/Clippy/tests/build/ZIP. It does not establish pixel-perfect 1:1 rendering against WeChat on the end-user's Windows 11 graphics driver, system font, DPI, or theme. Compare a screenshot of RustShot v0.6 side-by-side with the actual WeChat reference and adjust after visual feedback. Unimplemented functions are deliberately disabled rather than providing inert buttons that pretend to work.
