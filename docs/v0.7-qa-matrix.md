# RustShot v0.7.0 — Windows 11 regression and visual QA

The v0.7 focus is **readability, annotation styling and user settings**. OCR is explicitly out of scope. The icon remains disabled as a visual reference.

## Desktop verification

| Scenario | Expected |
| --- | --- |
| Full desktop width ≥1050 physical pixels | Toolbar 1000×68 physical pixels (unless screen is smaller) |
| Narrow desktop | Compact toolbar nominal 668×54 (clamped to desktop) |
| Selection near desktop bottom/right | Toolbar and palette remain inside virtual desktop and toolbar stays clickable |
| Large crop | Upper-left `width x height` text easily readable at 23px character height |
| Hover any icon | 19px character-height tip; long Chinese tooltips not clipped |
| Choose rectangle, then blue + 7px | Preview is blue/thick; saved PNG and clipboard match |
| Draw red arrow then change pen color to green | Existing red arrow keeps its original color |
| Text with Chinese IME | Input commits once; export uses selected text color |
| Use Undo/Redo across 3 different styles | Styles retained on each restored annotation |
| Mark mosaic area | Still obscures area, unaffected by stroke palette |
| Click unsupported OCR/scroll/pin/share | No screenshot completion or fake operation |
| Tray: disable PNG save | Clipboard still populated, no PNG created |
| Tray: disable clipboard copy | PNG still saved, no clipboard modification |
| Tray: restart after changing toggles | Settings loaded from HKCU\\Software\\RustShot |
| Tray: re-enable both | Both independent operations occur again |
| Long repeated capture with 4K screen | No new black/white flicker and no accumulating GDI handles |
| Mixed-DPI and negative monitor coordinates | Palette, toolbar and selection mouse targets align |

## Current technical scope

- Win32 + GDI with offscreen double-buffer retained.
- 5 fixed colors: red/blue/green/yellow/black.
- 3 fixed line thicknesses: 2/4/7 px, default 4.
- Per-annotation style persisted in in-memory history and included in raster export.
- Per-user registry toggles persist default-on AutoSave and AutoCopy.
- No OCR, no custom hotkey or directory picker, no full settings dialog, no pinning or long screenshots.
- CI demonstrates build and unit-test success **only**. Real Windows 11 screenshots are needed to verify visual scale, font, palette hit targets and IME behavior.
