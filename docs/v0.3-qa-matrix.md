# RustShot v0.3.0 — Windows 11 manual acceptance matrix

**Automated CI is not a substitute for interactive Windows 11 testing.**
Run on the actual Windows 11 PC before marking v0.3 stable.

| Case | Reproduction | Expected |
| --- | --- | --- |
| No configuration | Unzip and launch | App stays in tray, autostart is OFF |
| Screenshot | Alt+A then drag | Frozen background, green rectangle, toolbar |
| Window selection | Alt+A then hover + click | Correct foreground window bounds |
| Move and resize | Drag the 8 handles and inside selection | Valid rectangle, no negative width/height |
| Chinese annotation | Select Text, click inside crop, input 你好 using Microsoft Pinyin and press Enter to choose candidate | Candidate chosen inside edit, no early annotation commit |
| Finish Chinese annotation | Press Enter after composition finishes | Text remains visible and appears in saved PNG and pasted image |
| Cancel text | Text, type characters, press Esc | Discards active label but keeps screenshot selection |
| Multiple labels | Enter two English and Chinese labels | Both visible in exported image |
| Mosaic | Choose 马赛克 and drag over text | Pixelated region matches saved output, no pixels outside selected rect changed |
| History | Draw rectangle, mosaic, text; Ctrl+Z three times then Ctrl+Y | History deterministic for all three tools |
| Unicode file path | Run EXE from folder containing Chinese characters | Works and startup path remains valid |
| Start at login | Right-click tray, check 开机启动 | HKCU Run value appears, no UAC prompt |
| Startup disabled | Toggle again | HKCU Run value removed, unrelated Run values unchanged |
| EXE relocation | Enable autostart, move EXE elsewhere | Previously saved path is not silently counted as enabled; toggle at new path |
| Multiple DPI | 100% and 150% monitors, one located left of main | Hover/crop, handles, mosaic and text align |
| Load | 100 screenshots, 4K screenshot, 10h idle | No gradual GDI/USER handles increase, no crashes |
| Clipboard busy | Another app locks clipboard briefly | Error presented, PNG save still attempted |
| Cancel | Esc or right-click during capture | No new file, memory buffers discarded |

Test results should record: Windows 11 build, screen resolution, scaling, GPU, test case, expected/actual, screenshot, working set and GDI object count.

## Deferred from 0.3.0

WGC/DXGI engine comparison, better compression, rich text, color/size palettes, full Direct2D overlay, window snapping validation, OCR, pinning, scrolling capture, packaging and automated updater.

## Privacy

Mosaic is visual obfuscation, **not guaranteed redaction** for secrets. Use an opaque filled rectangle for passwords or keys until a dedicated secure-redaction tool is implemented.
